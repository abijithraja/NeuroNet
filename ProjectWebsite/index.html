DUELING DQN POLICY

Value stream & Advantage stream

Standard Q-networks conflate state quality with action selection. Decomposing Q(s,a) into V(s) and A(s,a) lets the agent learn when network conditions are inherently bad — independently of which action it evaluates — improving stability under sparse failure events.

Architecture Transfer

          
SmartGPU → NeuroNet

          
SmartGPU schedules GPU memory and compute kernels using deep RL. The MDP formulation transfers directly to network resource orchestration — buffer queues, bandwidth slices, and routing tables become elastic resources shaped by live traffic demand.

          
The mathematical equivalence between SM/VRAM scheduling and network queue management is the theoretical foundation of this project.

        


        

          
Proposed Research

          
Four-way workload agent

          
A multi-head architecture with specialised sub-agents for URLLC (sub-5 ms), eMBB (high throughput), mMTC (device density), and best-effort traffic. Single-policy networks cannot simultaneously optimise these conflicting SLA objectives.

          
Requires Pareto-optimal MARL formulation and per-slice reward decomposition.

        


        

          
Proposed Research

          
Closed-loop observe-act-verify-learn

          
Extend one-step dispatch into an asynchronous state machine: dispatch action → 30-second verification window → trigger inverse rollback if degradation continues → append full rollback trajectory to replay buffer.

          
Eliminates human intervention on failed remediations without removing the audit trail.

        


        

          
Proposed Research

          
CUDA acceleration + native ns-3

          
Compile the Dueling DQN into a TensorRT engine for direct CUDA execution, and replace the CSV adapter with a socket-level interface to the ns-3 discrete-event simulator for packet-level validation.

          
Target: sub-5 ms batched policy evaluation at 100+ Gbps with full ns-3 ground truth.
