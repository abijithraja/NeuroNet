# NeuroNet — Real Mininet Open vSwitch Integration

This module upgrades NeuroNet from a synthetic Python numerical simulator into a **real packet-level software-defined network (SDN)** running on **Mininet** and **Open vSwitch (OVS)**.

---

## 1. What Changes vs Synthetic Mode

| Feature | Synthetic Mode (`main.py` / `live_runner`) | Real Mininet Mode (`run_mininet.py`) |
| :--- | :--- | :--- |
| **Telemetry** | `np.random.normal()` formulas | Real **ICMP Ping RTT** + **Linux kernel `/sys/class/net`** byte stats |
| **Traffic** | None (mathematical abstractions) | Real UDP/TCP packet flows generated by **`iperf3`** |
| **Network Fabric** | In-memory Python dictionaries | **20 Open vSwitch (OVS)** virtual switches in Linux network namespaces |
| **Fault Injection** | Synthetic state variable changes | Real Linux Traffic Control (**`tc netem`**) delay/loss & link disconnection |
| **Remediation Action** | Math reduction (e.g. `latency * 0.58`) | **Real OpenFlow flow table rule modification (`ovs-ofctl`)** |

## 5. Topology Architecture

The 20-node topology ([`mininet/topology.py`](topology.py)) provides **disjoint redundant paths**:
- **Path A (Primary)**: `h1 -> e1 -> a1 -> c1 -> c2 -> a3 -> e5 -> h2`
- **Path B (Backup / Reroute)**: `h1 -> e1 -> a6 -> c4 -> c3 -> a4 -> e5 -> h2`

When the agent executes **`REROUTE`** or **`FAILOVER`**, an OpenFlow rule is dynamically injected via `ovs-ofctl` at the ingress switch `e1`:
```bash
ovs-ofctl add-flow e1 "priority=100,ip,nw_dst=10.0.0.2,actions=output:<port_to_a6>"
```
This physically steers live `iperf3` packets away from the impaired primary path to the healthy backup path, restoring latency and eliminating packet loss in real time.
